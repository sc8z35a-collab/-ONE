# プスラトゥーンONE / INK//SHIFT

第07高架街区のゲームプロジェクトです。Cloudflare 版のゲーム本体・サーバー・Android アプリを収録しています。

通常戦、NPC観戦、タイムレスバトルを Cloudflare Workers と SQLite Durable Objects で動かせます。1試合ごとにサーバールームを割り当てます。

## 起動する

Node.js 22 以降を使い、このファイルと同じフォルダーで実行します。

```bash
npm ci
npx wrangler login
npm run deploy
npm run access-code
```

最後のコマンドが求める値に、24〜160文字のランダムな接続キーを入力します。Cloudflareが表示した `workers.dev` のURLを開き、ゲーム開始時に同じキーを入力します。Workersの接続キーを設定するまで対戦の開始はロックされます。タイトル画面はURLから開けます。

## PCで試す

```bash
npm ci
cp .dev.vars.example .dev.vars
npm run check
npm run dry-run
npm run dev:cloud
```

ローカル試遊では `.dev.vars` の値を入力します。本番の接続キーは `npm run access-code` で設定します。

## プレイする

スマホではタイトル、試合中、横向きの案内画面から全画面に切り替えられます。埋め込み表示で制限がかかる場合は、案内の「新しいタブで開く」を使います。移動と射撃、ジャンプは別々の指で操作できます。射撃と潜水のボタンを両方押したとき、ボタンからの照準操作は射撃側の指を優先します。

NPC戦は地上の全景で始まり、「NPCを追う」で地下や車内も選手視点で観戦できます。ミニマップの「地上」「地下」で、対戦を進めながら両階層の塗りと面積を確認できます。「自動」で現在地の階層に戻ります。

描画はリニアHDRで、物理ベースの太陽光と空の環境光、カメラに追従するソフトシャドウ、画面空間アンビエントオクルージョン、ブルーム、フィルム調の色調で仕上げます。コンクリートの気孔や型枠目地、アスファルトの骨材と水たまりの映り込み、ガラス越しの室内、葉の塊になった植栽、塗装のはがれやさびを素材ごとに描き分け、箱形の物体も角に丸みのハイライトが乗ります。地下と車内は実際の照明器具の位置から光だまりと床への映り込みを計算します。キャラクターは丸みのある装甲、グローブ、ソール付きのブーツ、光るバイザー、インクが揺れる透明タンクを持ち、足元に接地影が付きます。

街は区画ごとに見えている範囲だけを描き、遠くは軽い形状に切り替えます。端末の処理が追いつかないときは描画解像度を自動で下げます。「軽量」は影を簡易にし、路面の映り込み・アンビエントオクルージョン・ブルームを省きます。

地上には30種類の集合住宅と、駅前売店、ミニスーパー、コンビニ、パン屋、カフェ、薬局、青果店、花屋、自転車店、コインランドリーがあります。集合住宅の敷地と基礎は棟の高さと建坪に合わせて広がります。雨だれ、ひび割れ、レンガや舗装など50種類の表面ディテールを建物と路面に使っています。道路から入れるマンション3棟は、各キャラが各棟に1試合1回入って室内を塗れます。木箱、レンガブロック、コンクリートブロックと、マンションや新店舗の窓ガラスはインクで壊せます。

地上は中心から半径500mです。外周街区に6形状×5仕様の軽量建物30種類、廃倉庫、コンビニ、駐車場を追加しました。外周では建物と地面にも塗れます。対戦の塗り得点は中央戦区、地下、線路、車内で集計します。高架道路へは南側の ROUTE 07 標識から坂道で上がれます。

B1は128×92の広さで、従来の約2倍の面積です。中央ホール、左右の通路、広場、店舗、地下駅を行き来して塗れます。街の四隅の階段からも歩いて降りられます。

列車は①地上西駅→②地上東駅→③地下東駅→④地下西駅→①地上西駅の順に、地上と地下を直通運転します。ホームと車内に4駅の路線と次駅、停車中は発車までの秒数を表示します。停車中に開いた扉へ歩くか「乗車」ボタン／Rで乗り、「降りる」ボタン／Rか開いた扉に向かって歩くと降ります。同じ階の別列車が待機中でも、乗れる列車を選びます。閉まった車体はすり抜けられません。

車内では移動・射撃・塗りを続けられます。乗降時にカメラの向きと上下角を維持します。車内外から窓を撃ち続けるとヒビが入り、割れた窓から弾が通ります。

メイン武器10種とサブウェポン5種をそれぞれ選択できます。メインとサブの消費を前版の半分にし、武器で塗る半径を約1.5倍にしました。ローラーは短押しで振り、長押ししながら移動すると転がして塗ります。遠くまで飛んだインク弾も、ステージ内の着弾地点を塗ります。敵や地形への命中位置に光の輪と飛沫が出ます。

撃つボタンを押したまま別の指でジャンプできます。ローラーは空中でインクを振り飛ばします。インクゲージの黄色い区間が次の1発で使う量です。画面左上にスーパー、サブ、ドローンが並び、被弾すると画面の縁が赤く光ります。タイトルの「武器を選ぶ」と、試合中の「武器変更」で装備を選べます。試合中の変更では、インク残量やクールダウンを引き継ぎます。

サブは画面のボタンか G で使います。投げボムは曲射と跳ね返り、時限ボムは3秒後の広範囲爆発、スライドボムは通路の塗りと接触爆発、トラップは接近検知、インクカーテンは敵弾の遮断に使います。使用時はインクと待ち時間を消費します。トラップとカーテンは各プレイヤーにつき同種1つまでです。

未塗装の床でもイカになれます。自チームのインク上では高速で泳ぎ、インクが速く回復します。塗った壁に向かってスティックを倒し、潜るボタンを押すと登れます。登っている間もスティックで横にずれたり、ジャンプで離れたりできます。敵インク上では移動速度、回復、スーパーの蓄積が徐々に下がります。初期タンク容量は150、スーパーギガチップ取得後は300です。壁・建物・設備の塗りは陣取り面積に含まれません。壁の着弾面積を前版から1.7倍にしました。床はインク膜の厚みと高さの差に応じて色と量を移し、壁の余分なインクは滴となって下の面に落ちます。

## NPCの動き

NPCは視界と発砲音から敵を探し、見失うと最後に見た場所を警戒します。屋内の家具や車体、インクカーテンで視線が遮られます。仲間が射線を維持する間に横から回り込み、遮蔽物が使える場所では身を出して数発撃ち、遮蔽へ戻ります。武器ごとに交戦距離と連射間隔が変わります。接近する敵弾、ボム、ボスとゼイアンの攻撃予告に反応して退避します。

急停止・旋回・横歩きでは脚、上半身、銃口が別の速さで動きます。踏んでいる足を床と階段に固定し、次の一歩までに引き上げます。当たり判定には描画と同じ姿勢を使います。経路選びでは敵インクと味方の目撃情報、階段、列車の発車時刻と損傷を考慮します。列車に乗ったNPCは車内でも戦い、予定の駅で降ります。

## 演算の分担

| Cloudflareで計算 | ブラウザで処理 |
| --- | --- |
| 24 Hzの対戦進行、移動、当たり判定、インク弾と粘性のあるインク膜 | 入力、照準カメラ、状態補間 |
| 塗り面積、体力、武器、5種のサブ、9種のスーパー、ドローン、チップ | 3D描画、音、HUD、ミニマップ |
| 全NPCの索敵・経路・接地・姿勢、ボスと襲撃、列車の運行・損傷・復旧 | 試合状態とインク差分の表示 |
| 手動照準が敵のどこに当たっているかと、ロック表示の対象 | ロック枠の投影とアニメーション |

デプロイ時に街・地下・車内の3D配置を事前生成し、Cloudflareの静的アセットから配信します。カメラに応じた光と画面の描画は、ブラウザのWebGLが担当します。接続中はWebSocketで入力を送り、画面に必要な状態とインクを受け取ります。対戦時刻はサーバーが刻みます。入力が450ミリ秒途切れると移動・射撃を解除し、復帰までの間もNPCや列車を動かします。無入力が8秒続くと対戦を保存して休止します。明示的なポーズでは対戦時刻もすぐ停止します。サーバー側のインク解像度は384×272で、画面の描画解像度は端末の品質設定で変えられます。演算移管の効果と操作遅延は端末のGPUと通信状態にも左右されます。

短い通信断からは自動で再接続します。同じタブで再読み込みした後は、同じ対戦モードを選び「続きから」で再開できます。部屋のメモリが解放された場合は、SQLiteに保存した試合状態から復元します。保存済みの弾、ドローン、発動中のスーパー、ブロックや窓の破損、マンションの入場履歴、NPCの進行中の経路と目撃情報も復元します。最後の保存まで少し巻き戻る場合があり、飛沫などの一時的な演出はリセットされます。再接続用のチケットは発行後72時間有効です。タイムレスバトルそのものに試合終了時刻はありません。

Cloudflareの利用枠はプランごとに異なります。運用時はWorkersのダッシュボードでDurable ObjectsのCPUと利用量を確認できます。

- [Cloudflare Durable Objectsの制限](https://developers.cloudflare.com/durable-objects/platform/limits/)
- [Cloudflare WebSocketの実行モデル](https://developers.cloudflare.com/durable-objects/best-practices/websockets/)

オオモノイカは触腕の薙ぎ払い、軌道が見えるインク砲、地面を広がる衝撃波で両チームを攻撃します。攻撃前に着弾範囲が地面に表示されます。照準に入った敵を追うロックオン表示は、照準や弾道を動かしません。

## Android APK

タイトル画面から Android 6.0 以降向けの APK 1.3 を入手できます。「INK//SHIFT 07」として、同じ署名の旧版に上書きできます。初回起動は端末内で遊べます。タイトル画面の「Cloudflare接続先」に、デプロイしたHTTPS URLを入力するとサーバー版が開きます。対戦開始時に先ほど設定した接続キーを入れてください。接続先を変更したり、端末内での試合に戻したりする場合も、同じボタンから操作します。

再ビルドにはJDK 21、Android SDK Platform 34、Build Tools 34.0.0を使います。`ANDROID_HOME`、`INKSHIFT_KEYSTORE`、`INKSHIFT_STORE_PASS_FILE` を設定し、`bash android/build-apk.sh` で `dist/inkshift-android.apk` を生成します。旧版に上書きインストールする場合は、アプリID `studio.icesmoker.inkshift.overpass` と署名鍵を揃えてビルドします。
